## Проверить на Mac перед установкой

- [ ] Выполнить форматтер и lint из README, затем Debug и Release-компиляцию.
- [ ] Запустить XCTest/XCUITest и изучить xcresult, исправить выявленные проблемы.
- [ ] Маленький экран: iPhone SE 3 / доступный аналог с iOS 17+.
- [ ] Большой экран: доступный Pro Max; портрет и landscape.
- [ ] Обзор: обычный текст, AX3–AX5, длинные названия, клавиатура, пустая выдача.
- [ ] Выбор категории: сетка превращается в одну колонку при accessibility-размерах.
- [ ] Системная, светлая, тёмная тема на всех вкладках и sheet.
- [ ] VoiceOver, Bold Text, Increase Contrast, Reduce Motion, Reduce Transparency.
- [ ] Все переходы назад, закрытие sheet, отмена и подтверждение удаления черновика.
- [ ] Избранное и черновик сохраняются после полного перезапуска.
- [ ] Выбранная точка появляется на карте как черновик.
- [ ] Геолокация: первый запрос, разрешение, отказ, повторное центрирование.
- [ ] Сеть отключена: локальные формы работают, отсутствие карт не выдаётся за их загрузку.
- [ ] Серверные функции обозначены как недоступные, оплат и отправки данных нет.
- [ ] Подписанный Release запускается на физическом iPhone.
