# Фактическая проверка — 16 ноября 2026

Windows, PowerShell, Python 3.12, Git. Исполняемые файлы `swift`, `xcodebuild`,
`xtool` не обнаружены в PATH. В WSL зарегистрирован только docker-desktop;
готовая среда xtool с Darwin SDK не обнаружена.

вызов `list_sims` вернул **Failed to list simulators: spawn xcrun ENOENT**.
Удалённая среда Mac с доступным Xcode этим инструментом не предоставлена.
Настройки подписи и сертификаты не запрашивались и не подменялись.

## Выполнено

- Tree-sitter Swift: синтаксический разбор всех 27 Swift-файлов, без ERROR/missing-узлов.
- Проверка Swift-файлов: строки не длиннее 100 символов, нет пробелов на концах строк.
- OpenStep parser: `project.pbxproj` разбирается, присутствуют три target:
  приложение, unit tests и UI tests; все ссылки на исходники/ресурсы существуют.
- Все Swift-исходники включены в build phases своих target.
- XML shared scheme и workspace корректно разбирается.
- Info.plist и PrivacyInfo.xcprivacy корректно разбираются как plist.
- Восемь JSON/config-файлов корректно разбираются.
- Четыре локальные записи имеют уникальные ID, допустимые рейтинги и координаты.
- Для каждой записи существует imageset с корректным файлом изображения;
  PNG иконки также открывается, размер 1024 × 1024, без alpha.
- `git diff --check` завершился без ошибок.

Синтаксический анализ **не проверяет типы Swift, доступность API или компиляцию SwiftUI**.
Перечисленные статические проверки не заменяют запуск приложения.

Инструменты проверки уже находившийся на D Tree-sitter и дополнительно скачанный
`openstep-parser 2.0.3` использованы вне приложения. Runtime-зависимостей у приложения нет.
Фотографии извлечены из предоставленного фото 2, исходные вложения не изменялись.

## Проверить на Mac перед установкой

- [ ] Выполнить форматтер и lint из README, затем Debug и Release-компиляцию.
- [ ] Запустить XCTest/XCUITest и изучить xcresult, исправить выявленные проблемы.
- [ ] Маленький экран: iPhone SE 3 / доступный аналог с iOS 17+.
- [ ] Большой экран: доступный Pro Max; портрет и landscape.
- [ ] Обзор: обычный текст, AX3–AX5, длинные названия, клавиатура, пустая выдача.
- [ ] Выбор категории: сетка превращается в одну колонку при accessibility-размерах.
- [ ] Системная, светлая, тёмная тема на всех вкладках и sheet.
- [ ] VoiceOver, Bold Text, Increase Contrast, Reduce Motion, Reduce Transparency.
- [ ] Все переходы назад, закрытие sheet, отмена и подтверждение удаления черновика.
- [ ] Избранное и черновик сохраняются после полного перезапуска.
- [ ] Выбранная точка появляется на карте как черновик.
- [ ] Геолокация: первый запрос, разрешение, отказ, повторное центрирование.
- [ ] Сеть отключена: локальные формы работают, отсутствие карт не выдаётся за их загрузку.
- [ ] Серверные функции обозначены как недоступные, оплат и отправки данных нет.
- [ ] Подписанный Release запускается на физическом iPhone.
- [ ] Сравнить со старым Nokhchi на одном устройстве и одном размере шрифта.

Образцы Apple используются как ориентир нативного поведения. Актуальные API сверялись
с [документацией MapKit](https://developer.apple.com/documentation/mapkit/map) и
[searchable](https://developer.apple.com/documentation/swiftui/view/searchable(text:placement:prompt:)).
Конфигурация форматтера основана на
[swift-format Configuration](https://github.com/swiftlang/swift-format/blob/main/Documentation/Configuration.md).
